# Siemens iX Icons

Selected SVG files from `@siemens/ix-icons` **3.4.0**, published by Siemens AG.

- Project: https://github.com/siemens/ix-icons
- Catalog: https://ix.siemens.io/docs/icons/icon-library
- Package source: https://cdn.jsdelivr.net/npm/@siemens/ix-icons@3.4.0/icons/index.mjs
- License: `LICENSE-SIEMENS-IX.txt` (MIT). Keep this notice and license when redistributing.

The page embeds a subset as SVG symbols so it works over HTTP and when opened locally. Decorative icons have `aria-hidden`; controls have visible labels or translated accessible names. Symbol fills use the inherited text color. The separate MQ favicon is an original project asset.
